扩展名称 / Extension Name：单一窗口智能填报助手扩展插件（SingleWindow Agent CDP Bridge）
最后更新 / Last Updated：2026-11-20

1. 数据收集与传输声明 / Data Collection & Transmission

本扩展程序不会收集、存储、出售或向任何第三方服务器传输您的个人身份信息、浏览历史、账号密码或网页内容。

All operations of this extension run strictly locally on the user's device. This extension does NOT collect, store, sell, or transmit your personal information, browsing history, credentials, or webpage contents to any external or third-party servers.

2. 本地通信说明 / Local Communication

  • 扩展仅在用户主动安装并连接本机运行的「原产地证明 Agent 工作台」后，通过本地回环地址（127.0.0.1 / localhost）与本机工作台进程进行 WebSocket 通信。
  • 仅在用户主动授权并选定目标标签页后，读取当前业务表单结构并回填用户已核对确认的申报字段。
  • The extension communicates exclusively with the user's local desktop workbench via loopback (127.0.0.1 / localhost), and only accesses the user-selected tab after explicit user authorization.

3. 本地存储 / Local Storage

扩展仅使用浏览器本地 chrome.storage.local 保存客户端随机标识（clientId）及用户自定义的浏览器备注名（alias），可随时通过卸载扩展清除。
